# Support Board

Небольшая внутренняя доска заявок поддержки: список, поиск по теме, фильтр по статусу,
сортировка, раскрытие карточки. Данные приходят из заглушки бэкенда (`src/api/tickets.ts`),
сеть не нужна.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

Стек: React 18 + TypeScript + Vite. Больше ничего не подключено — библиотеки можно
добавлять, если посчитаете нужным.

## Про использование ИИ

ИИ использовать можно — любым привычным вам инструментом, как в обычной работе.
Единственная просьба: перед обращением к нему коротко проговаривайте вслух, что
собираетесь спросить и какого ответа ждёте. Нам интересен ход мысли, а не скорость набора.

Гуглить, открывать документацию, запускать и отлаживать — всё разрешено.
Думать вслух приветствуется: незаконченная гипотеза полезнее молчания.

В шапке приложения есть счётчик «Рендеров строк» с кнопкой сброса — вспомогательный
инструмент, можно пользоваться, можно мерить по-своему.
